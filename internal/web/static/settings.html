Regex basics and guides
  • Plain text matches those characters. A pattern like STOP & SHOP can match anywhere in the merchant name.
  • ^ and $ mark the start and end. Use both to match the whole name.
  • [0-9] matches one digit. Add {4} for exactly four digits, or + for one or more.
  • A dot . matches any single character except a newline. Use \. for a literal period.

Fiscatoni ignores case and collapses whitespace in merchant names. Exact-name rules take precedence, followed by the first matching regex in the order shown in Settings.
